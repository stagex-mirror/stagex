# 2026-07-13 — StageX distro boot testing

## Milestone: busybox distro boots from squashfs! 🎉

### Problem
The squashfs root was missing `/proc`, `/sys`, `/dev`, `/mnt` mount points. mksquashfs strips empty directories, so mount points disappeared from the image.

### Root Cause Chain
1. `mksquashfs` strips empty dirs → `/proc`, `/sys`, `/dev`, `/mnt` missing in squashfs
2. After `switch_root`, devtmpfs mount was lost → `/dev` became part of read-only squashfs
3. Init script tried to create `/dev/null` on read-only fs → failed
4. Busybox init had no `/etc/inittab` → no getty, no login

### Fixes Applied (11 files modified + 3 new)
- **box-squashfs/src/box**: Creates mount points + `.keep` files before mksquashfs
- **box-cpio/src/box**: `-9` compression, excludes `./dev`
- **busybox Containerfile**: Added `/mnt` mount point + `.keep` to rootfs stage
- **busybox/src/initramfs/init**: Busybox-based initramfs with `switch_root`
- **busybox/src/init**: Mounts proc/sysfs/devtmpfs, detects state partition, exec `/bin/init`
- **busybox/src/rootfs/etc/inittab**: NEW — busybox inittab with getty on tty1 + ttyS0
- **busybox/src/rootfs/etc/init.d/rcS**: NEW — minimal boot script
- **grub.cfg**: Added `root=/dev/sda2 rootwait`
- **linux/server.config**: SquashFS + ATA support, async scan disabled
- **Makefile**: DISTRO=busybox default, box-cpio/box-squashfs/box-gpt loads

### Key Discovery
After `switch_root`, devtmpfs mount IS preserved through the new root. The `mknod: File exists` messages confirm device nodes survive the root switch.

### Current State
- busybox distro boots successfully from squashfs in QEMU
- Getty spawns on tty1 and ttyS0
- System stable for 1+ minute
- SSH not yet available (no SSH daemon in busybox distro)
