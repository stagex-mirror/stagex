# LLVM Patches

Most of these are sourced from Chimera Linux's cports, as intended for LLVM 21.
Inapplicable patches have been removed, hence why there are gaps in the
numbering, and some have been dropped as irrelevant/undesirable for StageX.
Note some potentially desirable patches have been classified as undesirable due
to increasing the distance from the upstream StageX, not due to objections to
the patches themselves.
